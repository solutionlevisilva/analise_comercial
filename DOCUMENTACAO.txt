================================================================================
🎯 ARQUIVOS PRINCIPAIS
================================================================================

1. main.py
----------
Aplicação Streamlit principal.

FUNCIONALIDADES:
- Upload de arquivo Excel (drag-and-drop)
- Carregamento de dados com pandas
- Limpeza automática:
  * Remove linhas completamente vazias
  * Remove duplicatas
- Cálculo automático de métricas
- Exibição de cards com métricas
- Preview dos dados em tabela

DEPENDÊNCIAS:
- streamlit
- pandas
- src.metricas

FLUXO:
1. Usuário faz upload do Excel
2. Pandas carrega os dados
3. Limpeza automática é aplicada
4. Métricas são calculadas
5. Interface exibe resultados


2. src/metricas.py
------------------
Módulo de cálculo de métricas comerciais.

FUNÇÕES:

calcular_total_processos(df)
  - Conta processos onde STATUS PAGAMENTO = "PAGO" ou "FATURADO"
  - Retorna: int (quantidade)

calcular_receita(df)
  - Soma VALOR DO PROCESSO onde STATUS = "PAGO" ou "FATURADO"
  - Retorna: float (receita total)

calcular_metricas(df)
  - Calcula todas as métricas de uma vez
  - Retorna: dict {'total_processos': int, 'receita': float}

formatar_metricas(metricas)
  - Formata valores para exibição
  - Retorna: dict com strings formatadas (R$ 1.234,56)

COLUNAS NECESSÁRIAS NO EXCEL:
- "STATUS PAGAMENTO" → Valores: "PAGO" ou "FATURADO"
- "VALOR DO PROCESSO" → Valores numéricos

================================================================================
📊 MÉTRICAS CALCULADAS
================================================================================

1. TOTAL DE PROCESSOS
---------------------
Descrição: Quantidade total de processos pagos ou faturados
Cálculo: COUNT onde STATUS PAGAMENTO in ["PAGO", "FATURADO"]
Formato: 1.234 (número inteiro com separador de milhares)


2. RECEITA TOTAL
----------------
Descrição: Soma do valor de todos os processos pagos/faturados
Cálculo: SUM(VALOR DO PROCESSO) onde STATUS in ["PAGO", "FATURADO"]
Formato: R$ 1.234.567,89 (moeda brasileira)

================================================================================
🔄 FLUXO DE DADOS
================================================================================

1. UPLOAD
---------
Excel (.xlsx/.xls) → uploaded_file (Streamlit)


2. CARREGAMENTO
---------------
uploaded_file → pd.read_excel() → DataFrame original


3. LIMPEZA
----------
DataFrame original → 
  - Remover linhas vazias (dropna(how='all'))
  - Remover duplicatas (drop_duplicates())
  → DataFrame limpo


4. CÁLCULO DE MÉTRICAS
----------------------
DataFrame limpo → 
  - calcular_total_processos()
  - calcular_receita()
  → dict de métricas


5. FORMATAÇÃO
-------------
Métricas (números) → formatar_metricas() → Métricas (strings formatadas)


6. EXIBIÇÃO
-----------
Métricas formatadas → st.metric() → Cards na interface

================================================================================
💾 SESSION STATE (STREAMLIT)
================================================================================

O Streamlit usa session_state para manter dados entre interações:

st.session_state.df_original
  - DataFrame original carregado do Excel
  - Usado como backup

st.session_state.df_limpo
  - DataFrame após limpeza
  - Usado para cálculos

st.session_state.metricas
  - Dicionário com métricas calculadas
  - {'total_processos': int, 'receita': float}
